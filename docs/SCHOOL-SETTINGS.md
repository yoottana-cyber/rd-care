# RD CONNECT — ตั้งค่าระบบโรงเรียน

เมนู **ตั้งค่าระบบโรงเรียน** ใช้สิทธิ์ **Admin** เท่านั้น (ตรวจสอบใน Worker API ไม่ใช่เพียง UI)

## ตั้งค่าที่บันทึกได้

- ชื่อโรงเรียน: ข้อมูลอ้างอิงในฐานข้อมูล (ยังไม่แก้ตราสัญลักษณ์หรือข้อความแบรนด์เดิมในทุกหน้า)
- ปีการศึกษา (พ.ศ. 2500–2700), ภาคเรียน 1/2, วันเปิดและปิดภาคเรียน (ระบุคู่กัน)
- เวลาเริ่มเรียนและเวลาเริ่มนับว่ามาสายตามเขตเวลา **Asia/Bangkok**; ต้องอยู่ระหว่าง 05:00–12:00 น. และเวลามาสายต้องไม่น้อยกว่าเวลาเริ่มเรียน

**สิ่งที่มีผลจริงทันที:** ค่า `late_cutoff_time` จะถูกอ่านจาก D1 ทุกครั้งก่อนนักเรียนสแกน QR มาสาย (ทั้ง QR ถาวรและ QR แบบหมุน) และก่อนครูออก QR แบบหมุน; ค่าเริ่มต้น 08:00 น. ใช้เงื่อนไข **หลังเวลา cutoff** (ไม่รวมเวลาเท่ากัน) หน้า QR พิมพ์และครูเวรแสดงค่าเดียวกัน

**ยังไม่มีผลต่อข้อมูลเดิม:** ปีการศึกษาและภาคเรียนยังเป็น metadata สำหรับ Admin ไม่บังคับปิดภาคเรียน ไม่ลบหรือย้ายประวัติเช็กชื่อย้อนหลัง และไม่เปลี่ยนตารางสอนอัตโนมัติ `school_start_time` ยังเป็น metadata ส่วนกลาง (สำหรับเชื่อมกับระบบเวลาเรียน/ตารางสอนในระยะถัดไป) การเช็กชื่อย้อนหลังยังใช้กติกาเดิม

## การตั้งค่าระบบอื่น

ใช้ทางลัดในหน้าเดียวกันเพื่อเข้าเมนูที่มีอยู่แล้ว:
- ฝ่ายกิจการนักเรียน: วันหยุดพิเศษ, เวลา/วันแจ้งเตือน, เกณฑ์คะแนน
- ครูและระบบ: บัญชีบุคลากร, ครูที่ปรึกษา, ตารางสอน

ไม่สร้างการตั้งค่าซ้ำ และไม่เปลี่ยนการทำงานของ Push หรือ VAPID

## Deploy และข้อมูลที่เก็บ

1. Merge `main` (Cloudflare Pages อัปเดต Frontend)
2. GitHub Actions **Deploy RD CONNECT Dev Worker** ต้องผ่านขั้น `Apply pending D1 migrations first` เพื่อใช้ `worker/migrations/0024_school_settings.sql` ก่อน Deploy Worker ที่เรียกตารางใหม่
3. ตรวจว่าหน้า `/api/health` ผ่าน แล้ว Login Admin และเปิดเมนูตั้งค่าระบบโรงเรียน
4. ทดสอบเปลี่ยน cutoff บนฐาน **Dev** ด้วยบัญชีจำลอง และตรวจข้อความบน QR print + เงื่อนไขหลัง cutoff
5. เมื่ออนุญาตใช้งานจริง ต้องแยก Worker/D1 Production จาก Dev สำรองข้อมูล และตรวจสิทธิ์/PDPA ก่อน

ค่าใหม่เก็บในตาราง `school_settings` แถว `id=1`; บันทึกการเปลี่ยนแปลงใน `school_settings_history` (ก่อน–หลังและผู้แก้ไข) และ `audit_logs` ภายใต้ D1 batch เดียวกัน

API: `GET /api/admin/school-settings`, `POST /api/admin/school-settings`; ใช้ Bearer Admin session ที่ผ่านการตรวจสอบเท่านั้น

**ห้าม** นำข้อมูลจริงเข้า Dev เพียงเพื่อทดลองหน้าเมนู
