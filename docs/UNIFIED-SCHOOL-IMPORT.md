# RD Care — นำเข้าข้อมูลนักเรียนทุกห้องในไฟล์เดียว (Dev)

## ไฟล์มาตรฐานเดียว: 6 คอลัมน์

หน้า **นักเรียน** → ส่วน **นำเข้านักเรียนและบัญชีจากทุกห้องในไฟล์เดียว**

```csv
classroom,roll_no,student_no,full_name,username,password
ม.1/1,1,DEMO9001,นักเรียนทดสอบ หนึ่ง,demo-stu01,Demo#1234
ม.2/3,2,DEMO9002,นักเรียนทดสอบ สอง,demo-stu02,Demo#5678
ม.3/2,3,DEMO9003,นักเรียนทดสอบ สาม,demo-stu03,Demo#9012
```

- classroom: ชื่อห้องให้ตรงกับห้องที่ตั้งค่าใน D1 เช่น ม.1/1–ม.6/7 (ไม่ใช่เลข ID ใน DB)
- roll_no: เลขที่ 1–100 ไม่ซ้ำภายในห้อง (เลขที่ 1 ซ้ำระหว่างคนละห้องได้)
- student_no: เลขประจำตัวนักเรียน ไม่ซ้ำทั้งโรงเรียน
- full_name: ชื่อ–สกุลนักเรียน
- username: ชื่อบัญชีที่กำหนดเอง 3–40 ตัว ภาษาอังกฤษ ตัวเลข `.`, `_`, `-`; ไม่ซ้ำกับบัญชีที่มีอยู่
- password: รหัสผ่าน 4–128 ตัว ควรใช้รหัสยาวและไม่ซ้ำ ห้ามใช้เลขประจำตัวประชาชน 13 หลัก

ไฟล์ CSV ตัวอย่างอยู่ที่ `web/templates/student-all-rooms-import.csv`; นอกจากนี้มีไฟล์ Excel ตัวอย่างพร้อมแผ่นงาน Rooms/Instructions ให้ดาวน์โหลดจากบทสนทนา

## ขั้นตอน

1. เลือกไฟล์ Excel `.xlsx` (Sheet 1) หรือ CSV UTF-8 ที่มีหัวตารางตามตัวอย่างทุกคอลัมน์
2. ระบบอ่านไฟล์ฝั่งเบราว์เซอร์และตรวจข้อมูลซ้ำ **ทั่วทั้งไฟล์** แม้ข้ามชุด/ข้ามห้อง
3. Worker ตรวจสิทธิ์ Admin, ห้องเรียนที่มีอยู่, เลขที่ซ้ำในแต่ละห้อง, รหัสนักเรียนซ้ำทั้งโรงเรียน, ชื่อผู้ใช้ซ้ำ และรูปแบบ Password
4. ถ้าพบข้อผิดพลาดใด ๆ ปุ่มยืนยันจะยังใช้งานไม่ได้ และแสดงเลขแถวเพื่อแก้ในไฟล์
5. เมื่อกดยืนยัน ระบบ **ทยอยนำเข้าทุกคนในไฟล์อัตโนมัติ** โดยแต่ละคำขอส่งไม่เกิน 10 คนเพื่อรักษา Cloudflare Worker CPU quota
6. ในแต่ละชุด Worker บันทึก `students`, `student_enrollments`, `portal_accounts` แบบธุรกรรม D1.batch และเก็บเพียง salted PBKDF2 hash ของรหัสผ่าน
7. หน้าเว็บแสดงความคืบหน้าจำนวนที่สำเร็จแล้วและปุ่มหยุดหลังจบชุดปัจจุบัน

**สำคัญ:** การนำเข้า 1 ไฟล์จำนวนมาก **ไม่ใช่ธุรกรรมเดียวของทั้งไฟล์** หากระบบขัดข้องระหว่างทาง รายการที่บันทึกสำเร็จไปแล้วจะคงอยู่ กรุณาตรวจรายชื่อใน Admin แล้วนำเข้าเฉพาะรายการที่ยังขาด โดยไม่กดซ้ำทั้งไฟล์โดยไม่ตรวจ

## ขีดจำกัดเชิงเทคนิค

ยกเลิกข้อจำกัด 10/60 คน **ต่อการนำเข้า 1 ไฟล์** แต่ยังมีข้อจำกัดด้านทรัพยากรที่สมเหตุสมผล: ไฟล์ไม่เกิน 8 MB, Sheet Excel ไม่เกิน 12,000 แถวต่อไฟล์, ตรวจผ่าน API ชุดละ 100 คน และบันทึกผ่าน API ชุดละ 10 คน จึงรองรับ ~1,800 คนในไฟล์เดียว. หากไฟล์ใหญ่มากให้แบ่งเป็นหลายไฟล์โดยยังใช้รูปแบบเดียวกัน

**ใช้ข้อมูลจำลองเท่านั้น** จนกว่าจะกำหนดกระบวนการพิสูจน์ตัวตน, PDPA, ความปลอดภัยบัญชี และทดสอบโหลดระดับโรงเรียนจริง
