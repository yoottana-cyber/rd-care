# RD Care — นักเรียนแจ้งมาสายด้วยตนเอง (ต้นแบบข้อมูลจำลอง)

## แนวทางความปลอดภัย
นักเรียนยังไม่มีบัญชีของตนเองใน RD Care จึงไม่เปิดให้กรอกเพียงรหัสนักเรียนเพื่อส่งคำขอ เพราะใครก็สามารถแอบอ้างได้

รุ่นทดลองนี้ใช้ **รหัสสุ่มเฉพาะนักเรียนหนึ่งคน ใช้ได้ครั้งเดียว อายุ 10 นาที** ซึ่งครูเวร/ฝ่ายกิจการนักเรียนหรือผู้ดูแลออกให้และแจ้งโดยตรง (ไม่โพสต์ในกลุ่มสาธารณะ).
Worker เก็บเฉพาะ SHA-256 ของรหัส 24 ตัวอักษร hex ที่สุ่มด้วย Web Crypto; **ไม่ได้เก็บรหัสต้นฉบับไว้ใน D1** และ API จะคืนรหัสให้ครูผู้สร้างแค่ครั้งนั้น.
การส่งคำขอไม่บันทึกเป็น `late_records` และไม่แก้ `attendance_daily` จนกว่าครูเวรจะยืนยัน

## วิธีทดสอบกับนักเรียนจำลอง

1. เข้าหน้าเว็บ RD Care ด้วยบัญชี Admin หรือ Staff (ครูเวรทดลอง)
2. เข้าเมนู **มาสาย** เลือกห้องที่มีนักเรียนจำลอง และวันที่ปัจจุบัน
3. ส่วน **ออกรหัสให้นักเรียนแจ้งมาสาย** เลือกนักเรียนและกดสร้างรหัส
4. จดรหัสชั่วคราว 24 ตัวอักษรไว้สำหรับนักเรียนจำลองเท่านั้น อย่าแชร์สาธารณะ
5. เปิดเว็บ RD Care ในหน้าต่างส่วนตัวหรืออีกเบราว์เซอร์ที่ยังไม่ Login
6. กด **นักเรียนแจ้งมาสาย** กรอกรหัสนักเรียนจำลอง รหัสชั่วคราว และเหตุผลตามต้องการ
7. กดส่งคำขอ เวลาเข้าระบบจะใช้ **เวลาที่เซิร์ฟเวอร์กำหนดใน Asia/Bangkok** ไม่ให้ผู้แจ้งแก้ไขเวลาเอง
8. กลับหน้า Staff → มาสาย → ห้องและวันที่เดียวกัน จะมีคำขอ **รอตรวจสอบ**
9. กด **ยืนยัน** เพื่อสร้าง late_records ที่ผ่านการตรวจสอบ หรือกด **ปฏิเสธ** เพื่อไม่บันทึกเป็นการมาสาย

## API

- `POST /api/late/self/code` (Bearer Staff/Admin) `{student_id}` → code ใช้ได้ 10 นาที
- `POST /api/student/late/report` (public มี code) `{student_no,code,reason?}` → pending
- `GET /api/late/self/requests?classroom_id=...&date=...` (Bearer Staff/Admin)
- `POST /api/late/self/requests/:id/review` (Bearer Staff/Admin) `{state:'verified'|'rejected'}`

Migration `worker/migrations/0005_late_self_requests.sql` เพิ่มตารางรหัสและคำขอแยกจากการบันทึกจริง

## ข้อจำกัดก่อน Pilot

- ยังไม่มี SSO/บัญชีนักเรียนและผู้ปกครอง จึงต้องมีครูเวรออกโค้ดรายคน
- ยังไม่ได้เพิ่มระบบแจ้งเตือนเมื่อครูเวรยืนยัน หรือการผูกผลมาสายกับเช็กชื่อรายวันโดยอัตโนมัติ
- การแจ้งมาสายหนึ่งครั้งต่อนักเรียนต่อวัน ไม่ใช่การแก้ไข/เปลี่ยนคำขอที่เคยถูกปฏิเสธ
- การทดสอบนี้ไม่ยืนยันตัวบุคคลแบบสมบูรณ์ เพราะผู้ที่ได้รับรหัสจากนักเรียนยังอาจแอบส่งแทนได้ ครูเวรต้องตรวจสอบอีกครั้ง
- ใช้เฉพาะข้อมูลสมมติบน `rd-care-dev` เท่านั้น และ **ห้ามนำข้อมูลนักเรียนจริงเข้าระบบ Dev**
