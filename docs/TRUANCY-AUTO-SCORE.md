# การหักคะแนนหนีเรียนอัตโนมัติ (-10 คะแนน) — RD CONNECT

## การทำงาน

เมื่อครูบันทึกการเช็กชื่อ **รายคาบ** เป็น `หนีเรียน` ระบบจะเพิ่มรายการคะแนนพฤติกรรมในหัวข้อ **หนีเรียน (-10)** โดยอัตโนมัติในธุรกรรมเดียวกันของ Cloudflare D1

- ใช้เกณฑ์ชื่อ **หนีเรียน**, หมวดความผิดปานกลาง (`moderate`), คะแนน `-10`
- บันทึกหนึ่งรายการต่อ **นักเรียน + ตารางสอน + วันที่เรียน**; คาบเดียวกันบันทึกซ้ำกี่ครั้งก็ไม่หักเพิ่ม
- คะแนนสะท้อนในหน้า คะแนนพฤติกรรม, ติดตามคะแนน, ประวัติของนักเรียนและผู้ปกครอง ตามระบบเดิม
- ไม่หักจากการขาดรายวัน หรือขาดรายคาบปกติ (`absent`) ต้องเลือกสถานะ **หนีเรียน** เท่านั้น
- ถ้าเปลี่ยนสถานะรายคาบจาก **หนีเรียน → มา/ขาดปกติ/สาย/ลา** ระบบจะคืน 10 คะแนนส่วนนี้โดยทำ soft-delete พร้อมบันทึก audit; ไม่ลบหลักฐาน
- ถ้าแก้กลับเป็น **หนีเรียน** อีก จะนำรายการคะแนนเดิมกลับมาเปิดใช้ ไม่สร้างรายการใหม่
- ระบบยังแจ้ง Push หนีเรียนตามเงื่อนไขเดิม (ไม่ได้เปลี่ยนระบบส่ง Push)
- การหักคะแนนนี้เริ่มกับ **เหตุการณ์ใหม่หลัง Migration** ไม่ไล่หักย้อนหลังจากรายการที่บันทึกหนีเรียนไว้ก่อนหน้าโดยไม่แจ้ง

## กันการบันทึกซ้ำ / การแก้ไขเกณฑ์

เกณฑ์อัตโนมัติจะมองเห็นในหน้า Admin/ฝ่ายกิจการนักเรียน โดยแสดงว่า *ระบบหักคะแนนอัตโนมัติ* แต่แก้ไขเกณฑ์นี้ผ่านหน้าเกณฑ์คะแนนไม่ได้ ผู้สอนไม่สามารถเลือกเกณฑ์เดียวกันจากหน้าบันทึกคะแนนทั่วไป และไม่สามารถลบรายการที่เกิดอัตโนมัติจากประวัติคะแนนโดยตรง ต้องแก้ไขสถานะรายคาบแทน เพื่อไม่ให้คะแนนขัดกับข้อมูลเช็กชื่อ

## Migration และการทดสอบ

- Migration: `worker/migrations/0027_truancy_auto_score.sql` สร้างเกณฑ์อัตโนมัติและตาราง `truancy_score_policy`, `truancy_behavior_links` พร้อม Trigger การสร้าง/คืนคะแนนเมื่อมีการเพิ่ม/ลบ `period_truancy`
- ไม่เปลี่ยน Primary Key ของ `attendance_period` หรือ `timetable`, ไม่ย้ายข้อมูลเช็กชื่อเดิม, ไม่รีเซ็ตคะแนนพฤติกรรม
- จำเป็นต้อง Apply Migration ใน D1 **ก่อน** Deploy Worker ใหม่เพราะ API เกณฑ์คะแนนมีการเรียกตารางใหม่
- หลัง Deploy ทดสอบกับนักเรียนทดสอบ: เช็กหนีเรียน → -10, เช็กซ้ำ → -10 เท่าเดิม, แก้เป็นมา → คืน 10, เปลี่ยนกลับหนีเรียน → -10 และตรวจประวัติ/Push ตามสิทธิ์
- ทดสอบ Migration SQLite: `python3 -m unittest discover -s tests -p 'truancy_auto_score_migration_test.py' -v`

**ข้อควรระวัง:** ข้อมูลคะแนนพฤติกรรมมีผลต่อการดูแลนักเรียน ครูควรตรวจสอบสถานะให้ถูกต้องก่อนบันทึก โดยเฉพาะกรณีที่ยังไม่ได้รับคำชี้แจงการไม่เข้าคาบ
