# RD Care — นำเข้าครูที่ปรึกษาจาก Excel/CSV (Dev)

## ใช้ไฟล์เดียวหลายห้องเรียน
เข้าสู่ระบบด้วยสิทธิ์ **Admin → ครูและระบบ → นำเข้าครูที่ปรึกษาหลายห้องในไฟล์เดียว** แล้วดาวน์โหลดไฟล์ Excel .xlsx (ฟอนต์ Tahoma) หรือ CSV UTF-8 จากหน้าเว็บ

**หัวตาราง 4 คอลัมน์:** classroom,full_name,username,password

```csv
classroom,full_name,username,password
ม.1/1,ครูตัวอย่าง หนึ่ง,teacher_demo01,DemoTeacher#1234
ม.2/3,ครูตัวอย่าง สอง,teacher_demo02,DemoTeacher#5678
ม.3/2,ครูตัวอย่าง สาม,teacher_demo03,DemoTeacher#9012
```

- classroom = ชื่อห้องในฐาน D1 ตามที่ตั้งค่าไว้
- full_name = ชื่อ–สกุลครู ไม่เกิน 100 ตัว
- username = อังกฤษ/ตัวเลข/จุด/ขีด 3–40 ตัว
- password = รหัสเริ่มต้น **4–128 ตัวสำหรับบัญชีครูใหม่** (แนะนำรหัสยาวและไม่ซ้ำกัน เพราะ 4 ตัวคาดเดาได้ง่าย)

**ครูมีบัญชีแล้ว:** ใส่ Username และชื่อ–สกุลให้ตรงกับบัญชีครู role=teacher ที่ยังใช้งาน แล้วเว้น Password ว่าง ระบบจะผูกห้องให้โดยไม่เปลี่ยนรหัสเดิม

**หนึ่งห้องต่อครูที่ปรึกษาหลักหนึ่งบัญชี:** D1 มีเพียง classrooms.advisor_user_id หากห้องมีครูอยู่ก่อนจะไม่เขียนทับ ต้องเปลี่ยนผ่านเมนูเดิมโดยตรวจสอบก่อน

**ชื่อผู้ใช้ไม่ซ้ำภายในหนึ่งไฟล์:** ถ้าครูดูแลหลายห้อง ให้สร้างบัญชีหนึ่งครั้ง แล้วนำเข้าไฟล์อีกชุดเพื่อผูกอีกห้องโดยเว้น Password ว่าง

## ขั้นตอน
1. เลือก Excel .xlsx หรือ CSV (ตรวจจับ UTF-8 และ Windows-874/TIS-620) หรือวาง CSV
2. กด **ตรวจสอบทั้งไฟล์ก่อนนำเข้า** เพื่อทวนชื่อห้อง ชื่อครู Username รหัสผ่าน บัญชีเดิม และห้องที่มีครูที่ปรึกษาอยู่แล้ว
3. แก้ไขรายการผิดพลาดก่อนยืนยัน ทุกแถวต้องผ่านการตรวจ
4. กด **ยืนยันนำเข้าครูที่ปรึกษาทั้งไฟล์** ระบบทยอยบันทึกอัตโนมัติชุดละไม่เกิน 5 ครู เพื่อลดการใช้ CPU แต่ไม่ได้จำกัดจำนวนทั้งไฟล์
5. Backend เขียน users (teacher), classroom advisor และ audit ใน D1.batch โดยเก็บ salted PBKDF2 hash ของรหัสผ่าน ไม่มีข้อมูล Password ในผล preview
6. หากเครือข่ายขัดข้องระหว่างชุด ให้ตรวจรายการที่บันทึกไปแล้วก่อนนำเข้าซ้ำ (ไม่มีธุรกรรมครอบคลุมทั้งไฟล์)

**Dev เท่านั้น:** ก่อนนำเข้ารายชื่อ/บัญชีครูจริง ต้องผ่านการประเมินความปลอดภัยสิทธิ์ผู้ใช้งาน การรีเซ็ตรหัสผ่าน และการคุ้มครองข้อมูลส่วนบุคคล
