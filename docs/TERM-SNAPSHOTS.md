# ชุดข้อมูลอ้างอิงรายภาคเรียน — RD CONNECT

หน้า Admin → **ทะเบียนและตารางสอนรายภาคเรียน** (หรือกดจากเมนูตั้งค่าระบบโรงเรียน)

## การทำงาน

- Admin เลือกปีการศึกษาและภาคเรียนที่กำหนดไว้ในเมนูตั้งค่าระบบโรงเรียน เพื่อดูจำนวนห้อง นักเรียนที่มีทะเบียน ณ วันที่ปัจจุบัน และตารางสอนที่เปิดใช้งาน
- เลือกห้องเพื่อดูรายชื่อนักเรียน (ใช้ `student_enrollments` ตามวันที่ ณ ปัจจุบัน) และครู/รายวิชาในตารางสอน
- กด **บันทึกชุดข้อมูลอ้างอิง** พร้อมยืนยันหนึ่งครั้ง เพื่อบันทึกภาพรวม ณ วันนั้นสำหรับปี/ภาคเรียนนั้น (ครั้งละ 1 ชุดต่อภาคเรียน)
- ต่อให้มีการย้ายห้องหรือแก้ตารางสอนในภายหลัง รายการอ้างอิงเดิมจะเก็บเลขที่ ห้อง ชื่อวิชา ผู้สอน และคาบเดิม โดยใช้ตาราง `school_term_snapshots`, `school_term_roster`, `school_term_lessons`
- Admin เปิดดูชุดที่เคยบันทึกไว้ย้อนหลังได้ตามปีและภาคเรียน โดยไม่อนุญาตให้เขียนทับ
- **ชื่อและเลขประจำตัวนักเรียน** ดึงจากตาราง `students` โดยสิทธิ์ Admin เท่านั้น หากมีการเปลี่ยนชื่อหรือระงับบัญชี ระบบไม่ทำสำเนาชื่อเก่าหรือรหัสผ่านไว้ในชุดข้อมูลอ้างอิง

## ข้อจำกัดสำคัญ

**นี่เป็นการแยกชุดข้อมูลอ้างอิง ไม่ใช่การสลับตารางสอนที่ใช้งานจริง** เพราะตาราง `timetable` เดิมมีข้อจำกัด UNIQUE ห้อง/วัน/คาบที่ยังไม่แยกตามภาคเรียน; การเปลี่ยนภาคเรียนอัตโนมัติขณะนี้อาจกระทบ Foreign Keys ของเช็กชื่อรายคาบ

- ห้ามเปิดภาคเรียนใหม่ด้วยการลบแถว `timetable` ที่ยังมีประวัติเช็กชื่อ
- การตั้งปีการศึกษา/ภาคเรียนยังไม่เปลี่ยนสิทธิ์ครู, ไม่ย้ายห้องนักเรียน, ไม่รีเซ็ตคะแนน, ไม่สร้างตารางสอนใหม่ให้เอง
- หากต้องการแยกตารางสอนที่ใช้งานจริงตามภาคเรียน ต้องทำขั้นตอนย้ายไปใช้ schema ใหม่โดยรักษา FK ของ `attendance_period`/`attendance_alerts` และส่วนรายงานย้อนหลัง พร้อมทดสอบ Migration กับฐานสำเนาก่อน

## การติดตั้ง

Migration เพิ่ม: `worker/migrations/0025_school_term_snapshots.sql`

เมื่อ Merge `main` ให้ GitHub Actions **Deploy RD CONNECT Dev Worker** ทำ migration ไปยังฐาน **rd-care-dev** ก่อนจึง Deploy Worker; หาก workflow นี้ไม่สำเร็จ หน้าใหม่จะยังใช้ไม่ได้

ทดสอบ SQL โดย `python3 -m unittest discover -s tests -p 'term_snapshots_migration_test.py' -v` และ JS โดย `node --test tests/term-snapshots.test.mjs`

ควรใช้ข้อมูลจำลองระหว่างการทดสอบก่อนใช้งานจริง
