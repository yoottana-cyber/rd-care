# จดจำการเข้าสู่ระบบ RD Care (คอมพิวเตอร์และ PWA)

ระบบรองรับการจดจำการเข้าสู่ระบบ **เป็นรายอุปกรณ์/โปรไฟล์เบราว์เซอร์**:

- บัญชีครู/ผู้ดูแล: ตัวเลือก **จดจำการเข้าสู่ระบบบนอุปกรณ์นี้** เปิดไว้เป็นค่าเริ่มต้น แต่เอาเครื่องหมายถูกออกได้หากใช้เครื่องส่วนรวม
- บัญชีนักเรียน/ผู้ปกครอง: มีตัวเลือกเดียวกันแต่ **ไม่ได้เปิดเป็นค่าเริ่มต้น** เพื่อปกป้องข้อมูลของนักเรียนบนเครื่องส่วนรวม
- เมื่อเลือกจดจำ เซิร์ฟเวอร์ให้ Session อายุสูงสุด **30 วัน** และเบราว์เซอร์เก็บ **token และเวลาหมดอายุ** ไว้ใน localStorage (ไม่เก็บรหัสผ่าน)
- เมื่อไม่เลือกจดจำ Session ยังคง **8 ชั่วโมง** และ token จะอยู่ใน sessionStorage เฉพาะแท็บที่ใช้งาน
- เมื่อปิดแล้วเปิด RD Care ใหม่ (เบราว์เซอร์หรือ PWA) ระบบจะลองตรวจสอบเซสชันเดิมผ่าน API ก่อนเข้า Dashboard โดยไม่ต้องกรอกรหัสผ่านอีก
- หากเครือข่ายล่มชั่วคราว จะ **ไม่ลบ token ที่ยังไม่หมดอายุ** แต่จะแสดงปุ่มลองเชื่อมต่ออีกครั้ง
- หาก API แจ้งหมดอายุ/ถูกถอนสิทธิ์ (401) จะล้าง token เดิม และให้เข้าสู่ระบบใหม่
- เมื่อกดออกจากระบบ ระบบเรียก API เพื่อยกเลิกเซสชันที่ใช้ จากนั้นล้าง sessionStorage/localStorage บนอุปกรณ์นี้
- บัญชีที่ถูกปิดใช้งานจะไม่ผ่านการตรวจ session แม้ token ยังไม่ครบ 30 วัน
- นักเรียน/ผู้ปกครองที่ต้องเปลี่ยนรหัสผ่านชั่วคราวจะ **ไม่จดจำเป็น 30 วัน** จนกว่าจะเปลี่ยนสำเร็จและเข้าสู่ระบบใหม่
- หากลงชื่อเข้าใช้บนคอมพิวเตอร์และมือถือคนละเครื่อง ต้องเข้าสู่ระบบ **อย่างน้อยครั้งแรกบนแต่ละเครื่อง** แล้วจึงจดจำแยกกัน
- หลังปล่อยเวอร์ชันนี้ ผู้ที่เคยเข้าสู่ระบบก่อนหน้าอาจต้องลงชื่อเข้าใช้อีกหนึ่งครั้งเพื่อรับเซสชันแบบใหม่

## ความปลอดภัยและข้อจำกัด

ระบบปัจจุบันใช้ opaque bearer token ใน localStorage เฉพาะกรณีที่เลือกจำการเข้าสู่ระบบ ซึ่งช่วยเรื่องความสะดวก แต่ token อาจมีความเสี่ยงหากอุปกรณ์ถูกผู้อื่นเข้าถึงหรือหน้าเว็บถูก XSS จึงควรทำเฉพาะอุปกรณ์ส่วนตัว และผ่านการทบทวนความปลอดภัยก่อนนำข้อมูลนักเรียนจริงเข้าใช้งาน ควรพิจารณา HttpOnly refresh cookies / token rotation เมื่อโครงสร้างโดเมนและระบบ Auth รองรับได้เต็มรูปแบบ

เมื่อใช้งานบนเครื่องสาธารณะ **อย่าเลือกจดจำ** และกด **ออกจากระบบ** ทุกครั้ง
