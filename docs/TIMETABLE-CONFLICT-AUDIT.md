# ตารางสอนครู — เพิ่มเองได้ทันที ไม่ต้องให้ Admin อนุมัติ

เมนู **ตารางสอนของฉัน** ให้ครูผู้สอนเพิ่มตารางเรียนและใช้งานเช็กชื่อรายคาบได้ทันที เมื่อไม่ชนรายการที่เปิดใช้งานอื่น ไม่มีคิวรออนุมัติ

การตรวจคาบซ้อนทำ 2 ชั้น: (1) ตรวจจาก API ก่อนบันทึก เพื่อแจ้งครูว่าคาบซ้อน (2) Trigger ใน D1 เพิ่มเติมใน migration `0026_timetable_clash_guards.sql` เพื่อป้องกันกรณีบันทึกพร้อมกันจากอุปกรณ์หลายเครื่อง โดยตรวจทั้งคาบเดี่ยว/คาบคู่ของครูคนเดียวกันหรือห้องเรียนเดียวกัน

**Admin** มีเมนู **ตรวจสอบตารางสอน** สำหรับเปิดดูรายการทุกห้องและทุกครู เลือกห้อง ครู ค้นหารายวิชา และกรองเฉพาะคาบชนกัน หน้า Admin เป็นข้อมูลอ่านอย่างเดียว ไม่มีการอนุมัติ/ปฏิเสธ

### การติดตั้งอย่างปลอดภัย

Migration นี้ **สร้าง Trigger ใหม่เท่านั้น** ไม่ลบหรือสร้างตาราง `timetable` ใหม่ ไม่เปลี่ยน `timetable.id` และไม่มีผลต่อความสัมพันธ์ประวัติเช็กชื่อ

ต้องให้ Workflow ฝั่ง Worker Apply migration สำเร็จก่อน Deploy เพื่อให้การป้องกันกรณีบันทึกพร้อมกันมีผล ทดลองเพิ่มคาบคู่ที่ชนกับคาบเดิม ต้องได้รับ HTTP 409; รายการคาบเดิมที่ชนกันก่อนเพิ่ม Trigger ยังแสดงให้ Admin ตรวจในหน้า Audit ได้

**หมายเหตุ:** ตาราง `timetable` เดิมยังมี UNIQUE(ห้อง,วัน,คาบ) และไม่รองรับการสร้างรายการคาบเดียวกันของห้องเดิมในสองภาคเรียนต่างกันอย่างปลอดภัย งานแยกตารางสอนตามภาคเรียนจริงจึงยังไม่รวมใน PR นี้; ต้องออกแบบ schema ใหม่โดยรักษา Foreign Key ของประวัติเช็กชื่อก่อน
