# ตั้งค่าเวลาคาบเรียน พักกลางวัน และพักระหว่างคาบ — RD CONNECT

## การตั้งค่าสำหรับ Admin

เข้า **ตั้งค่าระบบโรงเรียน → ตั้งค่าเวลาคาบเรียน** กำหนดค่า:

- เวลาเริ่มคาบที่ 1 (เดิมเริ่มต้น 08:30)
- ความยาวคาบเรียน **ปกติ 50 นาที / ร่นคาบ 45 นาที / ร่นคาบ 40 นาที**
- **เริ่มพักกลางวันหลังคาบใด:** ปิดพักกลางวัน หรือเลือกหลังคาบที่ 1–9
- **ระยะเวลาพักกลางวัน:** 15–180 นาทีเมื่อเปิดใช้งาน
- **พักระหว่างคาบทั่วไป:** 0–30 นาที

เมื่อเลือกพักกลางวันหลังคาบที่ 4 เป็นต้น จะให้พักที่รอยต่อระหว่างคาบ 4 และ 5 โดย **พักกลางวันแทนพักระหว่างคาบ** ตรงจุดนั้น ไม่บวกเวลาพักระหว่างคาบซ้ำซ้อน

ค่าเริ่มต้นจาก Migration ใหม่คือ **ไม่มีพักกลางวันและไม่มีพักระหว่างคาบ** เพื่อไม่สมมติตารางเวลาที่โรงเรียนยังไม่ได้ตั้งค่า และเพื่อรักษาเวลาในตารางเดิมทุกประการ ผู้ดูแลต้องเลือกเวลาพักตามประกาศของโรงเรียนก่อนใช้งานอ้างอิงจริง

## ตัวอย่างการคำนวณ

คาบที่ 1 เริ่ม 08:30 น., คาบละ 50 นาที, พักทั่วไป 5 นาที, พักกลางวันหลังคาบที่ 4 เป็นเวลา 60 นาที:

| รายการ | เวลา |
|---|---|
| คาบ 1 | 08:30–09:20 |
| พักระหว่างคาบ | 09:20–09:25 |
| คาบ 2 | 09:25–10:15 |
| พักระหว่างคาบ | 10:15–10:20 |
| คาบ 3 | 10:20–11:10 |
| พักระหว่างคาบ | 11:10–11:15 |
| คาบ 4 | 11:15–12:05 |
| พักกลางวัน | 12:05–13:05 |
| คาบ 5 | 13:05–13:55 |

ตัวอย่างการคำนวณ **ยังไม่รวมการเข้าแถว กิจกรรมพิเศษ หรือเวลาพักแบบเฉพาะวัน** ที่ไม่ได้กำหนดในเมนูนี้

## การใช้งานและความปลอดภัย

- Admin เห็นตารางตัวอย่าง 10 คาบและช่วงพักแบบสดก่อนกดบันทึก และประวัติแก้ไขข้อมูลพร้อมผู้ดำเนินการ
- ครูเห็นเวลาอ้างอิงใน **ตารางสอนของฉัน** และ **เช็กชื่อรายคาบ** โดย API อ่านอย่างเดียว `GET /api/school/period-clock` ที่ใช้สิทธิ์ teacher, staff, admin เท่านั้น
- หากวิชาคาบคู่พาดผ่านช่วงพัก เวลาอ้างอิงจะระบุ **(มีช่วงพัก)** เพื่อไม่ทำให้เข้าใจว่าคาบนั้นยาวต่อเนื่องโดยไม่มีพัก
- การตั้งค่าพักมีผลกับการแสดงเวลาอ้างอิง **ปัจจุบัน** ไม่จัดตารางสอนใหม่ ไม่ปรับการตรวจชนคาบ ไม่เพิ่มสิทธิ์เช็กชื่อ และไม่แก้ประวัติรายคาบ หรือเวลาสแกน QR มาสาย

## Deploy

Migration ใหม่ `worker/migrations/0029_school_lunch_and_recess.sql` เพิ่มเพียง 3 คอลัมน์ใน `school_settings` โดยไม่แตะตารางนักเรียนและการเข้าเรียนเดิม

ต้อง Apply Migration **0028** และ **0029** ใน D1 ให้เรียบร้อย **ก่อน Deploy** Worker API และ Pages frontend ใหม่ เพื่อไม่ให้ API query คอลัมน์ที่ยังไม่พร้อมใช้งาน

ทดสอบ `node --test tests/school-period-clock.test.mjs tests/school-settings.test.mjs` และ `python3 -m unittest discover -s tests -p 'school_period_clock_migration_test.py' -v`.
