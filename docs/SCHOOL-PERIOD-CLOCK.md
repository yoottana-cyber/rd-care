# ตั้งค่าความยาวคาบเรียน — RD CONNECT

ผู้ดูแลระบบ (**Admin**) เปิดเมนู **ตั้งค่าระบบโรงเรียน → ตั้งค่าเวลาคาบเรียน**

- **ปกติ 50 นาที** (ค่าเริ่มต้น)
- **ร่นคาบ 45 นาที**
- **ร่นคาบ 40 นาที**
- ตั้งเวลาเริ่ม **คาบที่ 1** แยกจากเวลาเริ่มเรียน/เกณฑ์ QR มาสาย (ค่าเริ่มต้น 08:30 น.) รองรับ 05:00–18:00 น.
- ดูตัวอย่าง **คาบที่ 1–10** ได้แบบทันที ก่อนกดบันทึก
- เมื่อบันทึกแล้ว ครูจะเห็นเวลาอ้างอิงตามรูปแบบล่าสุดใน **ตารางสอนของฉัน** และ **ตารางเช็กชื่อรายคาบ**
- ปรับเวลาได้โดยไม่แก้เลขคาบ ตำแหน่งวิชา ผู้รับผิดชอบ สิทธิ์การเช็กชื่อ หรือประวัติรายคาบ
- หน้าประวัติการตั้งค่าบันทึกผู้แก้ไขและค่าก่อน–หลังเช่นเดียวกับการตั้งค่าระบบโรงเรียนอื่น

**สำคัญ:** ตารางตัวอย่างสร้างจากช่วงเวลาต่อเนื่อง 10 คาบ ยังไม่ใส่เวลาพักกลางวัน พักระหว่างคาบ พิธีหน้าเสาธง หรือกิจกรรมพิเศษ เนื่องจากข้อมูลเหล่านี้ไม่ได้กำหนดไว้ในระบบ จึงไม่ควรนำช่วงเวลาตัวอย่างไปใช้เป็นประกาศเวลาเรียนจริงโดยยังไม่ตรวจสอบช่วงพัก

API: `GET /api/school/period-clock` ให้ครู/เจ้าหน้าที่/Admin ที่ผ่าน Login อ่านได้เฉพาะ `first_period_start_time` และ `period_duration_minutes`; การแก้ไขต้องใช้ `POST /api/admin/school-settings` สำหรับ Admin เท่านั้น

Migration: `worker/migrations/0028_school_period_clock.sql` เป็นการเพิ่มคอลัมน์ใน `school_settings` เท่านั้น ต้อง Apply D1 Migration ให้สำเร็จ **ก่อน** Deploy Worker API และ Cloudflare Pages หน้าใหม่ ค่าเริ่มต้น 50 นาที ไม่แก้ `attendance_period`, `timetable`, `school_start_time`, `late_cutoff_time` หรือข้อมูลย้อนหลัง
