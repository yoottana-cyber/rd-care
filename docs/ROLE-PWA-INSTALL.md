# ติดตั้ง RD CONNECT แยก 3 แอปบนหน้าจอโฮม

RD CONNECT มีแอป PWA 3 ตัวที่แชร์เว็บไซต์และฐานข้อมูลเดียวกัน แต่มี **รหัสแอป Manifest**, **ชื่อไอคอน**, **สีไอคอน** และ **หน้าเปิดเริ่มต้น** แยกตามประเภทผู้ใช้:

| ประเภท | ลิงก์สำหรับติดตั้ง | ชื่อแอป | ไอคอน |
| --- | --- | --- | --- |
| ครูและบุคลากร (รวม Admin) | https://rd-care.pages.dev/?login=staff | RD ครู | เขียว |
| นักเรียน | https://rd-care.pages.dev/?login=student | RD นักเรียน | น้ำเงิน |
| ผู้ปกครอง | https://rd-care.pages.dev/?login=guardian | RD ผู้ปกครอง | ม่วง |

**เมื่อเปิดจากไอคอนที่ติดตั้งแล้ว จะเข้าหน้าหรือเข้าสู่ระบบของประเภทนั้นทันที โดยไม่ต้องเลือกบทบาทอีก** ถ้าได้เลือก "จดจำการเข้าสู่ระบบ" และเซสชันยังใช้ได้ ระบบจะแสดงหน้าหลักได้เลย ส่วนบัญชีที่หมดอายุหรือไม่จดจำไว้จะเห็นแบบฟอร์มเข้าสู่ระบบของบทบาทที่ติดตั้ง

## Android / Chrome

1. เปิด **ลิงก์เฉพาะบทบาท** ข้างต้นด้วย Chrome
2. กดปุ่ม **ติดตั้งแอป RD CONNECT [บทบาท]** บนหน้าล็อกอิน หรือเลือกเมนู Chrome → **ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก**
3. ตรวจดูชื่อแอป แล้วกดติดตั้ง
4. กลับมาเปิดลิงก์ของอีกบทบาทหนึ่งหากต้องการไอคอนอีกแอป

Chrome ใช้ค่า `id` ที่ต่างกันใน `manifest-staff.webmanifest`, `manifest-student.webmanifest`, และ `manifest-guardian.webmanifest` เพื่อแยกตัวตนแอปแม้อยู่บนโดเมนเดียวกัน

## iPhone / Safari

1. เปิดลิงก์บทบาทนั้นใน **Safari** (อย่าเปิดหน้าเลือกผู้ใช้ทั่วไป)
2. กด **แชร์ → เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
3. ตรวจชื่อ **RD CONNECT ครู / นักเรียน / ผู้ปกครอง** แล้วเพิ่ม
4. ทำซ้ำจากลิงก์ของอีกบทบาท เพื่อสร้างไอคอนคนละอัน

Safari จะบันทึก URL ของหน้าเฉพาะบทบาทเมื่อเพิ่มลงหน้าจอโฮม ชื่อและ Apple touch icon ถูกตั้งให้ตรงบทบาทผ่าน `pwa-role.js`.

## สำหรับผู้ที่เคยติดตั้งไอคอน RD CONNECT แบบเดิม

ไอคอนที่ติดตั้งไว้ก่อนหน้าเป็น **แอปเดียว** และไม่สามารถแยกเป็นสามแอปโดยสั่งจากเว็บไซต์ได้ อาจเปิดสู่ประเภทผู้ใช้ล่าสุดโดยอัตโนมัติหลังปรับปรุง แต่ถ้าต้องการ **3 ไอคอนแยก** ให้ลบเฉพาะไอคอนแอปเดิมออกจากหน้าจอโฮม แล้วติดตั้งผ่านลิงก์เฉพาะบทบาทใหม่

การลบไอคอน **ไม่ใช่** การลบบัญชีหรือข้อมูลในฐานข้อมูล โรงเรียนไม่ต้องออกบัญชีใหม่ ไม่ต้องเปลี่ยน URL, VAPID key, QR มาสาย หรือระบบ Push ทั้งนี้อุปกรณ์บางรุ่นอาจต้องเปิดอนุญาตแจ้งเตือนอีกครั้งหลังติดตั้งใหม่ โปรดตรวจสอบที่เมนูการแจ้งเตือนของบทบาทนั้น

## พฤติกรรมสำคัญด้านความปลอดภัย

- ใช้การตรวจสิทธิ์เดิมบนเซิร์ฟเวอร์ทุกคำขอ การติดตั้งไอคอนหนึ่งไม่ได้ให้สิทธิ์ของอีกบทบาท
- เซสชันนักเรียน/ผู้ปกครองที่เลือกจดจำถูกแยกคีย์ตามบทบาทแล้ว เพื่อให้ใช้ทั้งสองแอปบนเครื่องเดียวกันได้ (ยังรองรับการคืนค่าเซสชันเดิมในช่วงเปลี่ยนผ่าน)
- แอปครูใช้ `rd_token` ส่วนแอปนักเรียน/ผู้ปกครองใช้ Portal Authentication เดิม
- ทั้งสามแอปยังใช้ Service Worker ของระบบเดิม โฟลว์ Push และ Deep Link ของนักเรียนมาสาย/ผู้ปกครองยังตรวจบทบาทก่อนแสดงข้อมูล
- ควรทดสอบการติดตั้งจริงทั้ง Android และ iOS หลัง Cloudflare Pages เผยแพร่เวอร์ชันใหม่ และตรวจการแจ้งเตือนบนอุปกรณ์อย่างน้อยหนึ่งเครื่องต่อบทบาท
