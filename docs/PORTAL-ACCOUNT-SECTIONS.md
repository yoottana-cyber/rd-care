# RD CONNECT — เมนู Admin สำหรับบัญชีนักเรียน ผู้ปกครอง และความสัมพันธ์

ปรับแยกส่วนงานเดิม “บัญชีผู้เรียน/ผู้ปกครอง” เป็น 3 เมนู ภายใต้ **งานบริหารระบบ** (Admin เท่านั้น)

| เมนู | ใช้ทำอะไร |
|---|---|
| **บัญชีนักเรียน** | ค้นหา Username, ชื่อ, เลขประจำตัว / ห้องเรียน; สร้างบัญชีรายคน; สร้างทั้งห้อง; นำเข้าบัญชีทั้งโรงเรียนด้วย CSV/Excel; รีเซ็ตและเปลี่ยนสถานะ |
| **บัญชีผู้ปกครอง** | สร้างบัญชีรายคนพร้อมกำหนด Username/Password; นำเข้า CSV/Excel ร่วมกับนักเรียน; ค้นหาและจัดการบัญชี; รีเซ็ตและเปลี่ยนสถานะ |
| **ความสัมพันธ์ผู้ปกครอง** | เลือกห้องเรียน ค้นหาและเลือกบัญชีผู้ปกครอง ตรวจสอบความสัมพันธ์ก่อนเชื่อม; ดูและค้นหาประวัติความสัมพันธ์; เพิกถอนการเชื่อมบัญชี |

หน้า Admin แต่ละหน้ามีแผงสรุป **จำนวนบัญชีนักเรียน, บัญชีผู้ปกครอง, ความสัมพันธ์, นักเรียนที่ยังไม่มีผู้ปกครองที่ใช้งานอยู่** เพื่อให้เห็นภาพรวมก่อนทำรายการ

## แสดงจำนวนแถว

ในแต่ละเมนูเลือก **10 / 25 / 50 / 100 แถว หรือ ทั้งหมด** จากเมนู “แสดงข้อมูล”

- ค่าเริ่มต้น **25 แถว** และจดจำตัวเลือกแยกตามเมนูใน sessionStorage บนเบราว์เซอร์
- ถ้าเลือก 10/25/50/100 มีปุ่ม **ก่อนหน้า / ถัดไป** และแสดงจำนวนรายการที่ตรงเงื่อนไข พร้อมหน้าปัจจุบัน
- ค้นหา **ชื่อ Username เลขประจำตัวนักเรียน** โดยค้นที่ฐานข้อมูลก่อนนับและแบ่งหน้า (เมนูความสัมพันธ์ค้นได้ทั้งข้อมูลนักเรียนและผู้ปกครอง)
- เลือก **ทั้งหมด** จะโหลดข้อมูลครบผ่าน API ครั้งละ 250 แถวภายในโดยอัตโนมัติ พร้อมแสดงความคืบหน้า **ไม่ติดเพดาน 3,000 บัญชี หรือ 4,000 ความสัมพันธ์ของ API เดิม**
- ถ้าข้อมูลหลายหมื่นแถว การแสดงทั้งหมดอาจทำให้เบราว์เซอร์ใช้หน่วยความจำสูง เลือกแสดง 100 แถวและค้นหาจะตอบสนองเร็วกว่า

## การคงข้อมูลและสิทธิ์

- API `/api/admin/portal/accounts?role=student|guardian&page=N&limit=10|25|50|100|250&q=...` คืน `items,total,page,limit,has_more`
- API `/api/admin/portal/links?page=N&limit=...&q=...` คืนข้อมูลความสัมพันธ์แบบเดียวกัน
- API `/api/admin/portal/summary` คืนสถิติภาพรวม
- API `/api/admin/portal/room-status?classroom_id=N` คืนบัญชีนักเรียนในห้องเพื่อการสร้างบัญชีทั้งห้องให้ถูกต้อง แม้บัญชีโรงเรียนมากกว่า 3,000 รายการ
- ทุก API ตรวจสิทธิ์ **admin** บนเซิร์ฟเวอร์ ไม่ให้ครูทั่วไป นักเรียน และผู้ปกครองดูข้อมูลบัญชีหรือความสัมพันธ์ทั้งโรงเรียน
- การนำเข้า/อัปเดตไฟล์ทั้งโรงเรียนยังอยู่ในเมนูบัญชีนักเรียนและบัญชีผู้ปกครอง โดยใช้เลขประจำตัวนักเรียนเชื่อมดังเดิม
- ไม่เปลี่ยนเลขบัญชี ไม่ลบข้อมูลเดิม ไม่แก้รหัสผ่านหรือความสัมพันธ์จากการเปลี่ยนจำนวนแถว

## การตรวจสอบ

ชุดทดสอบ `tests/portal-account-pagination.test.mjs` ตรวจ:
1. ตัวเลือกจำนวนแถวทั้ง 5 ค่า และการคำนวณหน้าที่ถูกต้อง
2. กรณีจำนวนมากกว่า 4,000 สามารถอ่านครบด้วย “ทั้งหมด”
3. API ไม่มีเพดานแบบเก่าและตรวจสิทธิ์ Admin
4. หน้า Admin ทั้งสามแยกส่วนสร้าง/เชื่อมบัญชีและมีปุ่มเปลี่ยนหน้า
5. การนำเข้าเดิมยังใช้งานในเมนูบัญชีนักเรียน/ผู้ปกครอง

อย่าลืมตรวจ Cloudflare Pages Deploy และทดสอบบนเบราว์เซอร์/มือถือจริง รวมถึงการอัปเดต Service Worker (`rd-care-shell-v72`) หลังเผยแพร่
