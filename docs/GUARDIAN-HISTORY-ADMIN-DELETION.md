# RD CONNECT — ผู้ปกครองดูประวัติ และ Admin ลบบัญชีอย่างปลอดภัย

## หน้าผู้ปกครอง

URL เดิม `https://rd-care.pages.dev/?login=guardian`

เมื่อเข้าสู่ระบบ บัญชีผู้ปกครองจะดูข้อมูลได้ **เฉพาะนักเรียนที่โรงเรียนยืนยันความสัมพันธ์แล้ว** ผ่าน `guardian_student_links`; ไม่สามารถเปลี่ยน student_id ใน URL เพื่อดูนักเรียนอื่นได้

1. **มาเรียน:** ประวัติเช็กชื่อรายวันและรายคาบ รายวิชาและคาบเรียน
2. **หนีเรียน:** ประวัติรายการรายคาบที่ครูบันทึกหนีเรียน แยกจากการแจ้งเตือน Push โดยยึดสถานะในฐานข้อมูล ณ วันที่แสดง
3. **คะแนน:** ดูความผิดสะสม คะแนนปรับพฤติกรรมแล้ว ความผิดคงเหลือ และคะแนนความดี โดย **คะแนนความดีไม่ถูกนำมาหักคะแนนความผิด**
4. เปิดครั้งแรกแสดง **30 วันล่าสุด** และเลือกวันนี้/เลือกวัน/ช่วงวันที่ได้ **สูงสุด 90 วันต่อครั้ง** ผู้ปกครองที่ผูกนักเรียนหลายคนเลือกบุตรหลานได้จากแต่ละหน้าประวัติโดยตรง
5. การแจ้งเตือน Push เดิมยังอยู่ โดยหน้าแรกมีทางลัดไปหน้าแจ้งเตือน

API `GET /api/portal/records?student_id=...&from=...&to=...` ตรวจสิทธิ์นักเรียนที่เชื่อมจริง และคืนรายการ `daily`, `period`, `truancy`, `behavior`, `good` และยอด `behavior_deducted`, `behavior_adjusted`, `behavior_remaining`, `good_total`.

## ผู้ดูแลระบบลบข้อมูล/บัญชี

Admin มีปุ่ม **ลบ** 3 ส่วน โดยต้องพิมพ์ชื่อ Username หรือเลขประจำตัวนักเรียนให้ถูกต้อง **ทั้งหน้าจอและฝั่งเซิร์ฟเวอร์** ก่อนทำรายการ ระบบไม่อนุญาตให้ครูทั่วไปลบผ่าน API

| ตำแหน่ง | สิ่งที่ถูกลบ/ถอนออก | สิ่งที่ไม่ลบ |
|---|---|---|
| ครูและระบบ → บัญชีบุคลากร | ถอนบัญชีครู/ฝ่ายกิจการนักเรียน, เพิกถอน Session/Push/สิทธิ์/ครูที่ปรึกษา, ซ่อนจากบัญชีที่ใช้งาน, ไม่สามารถล็อกอิน | ประวัติการเช็กชื่อและงานสอนเก่า (เก็บด้วย ID เดิมและแทนที่ชื่อ) |
| จัดการนักเรียน → ลบข้อมูล | ถอนข้อมูลออกจากรายชื่อที่ใช้งาน, ถอนบัญชีนักเรียนและลิงก์ผู้ปกครอง, ปิดการเข้าถึงทุกช่องทาง และทำให้รหัสนักเรียน/ชื่อกลายเป็นค่าเก็บประวัติ | รายการเช็กชื่อ คะแนน ความผิด ประวัติกิจการนักเรียน (ไม่ลบย้อนหลัง) |
| บัญชีนักเรียน / ผู้ปกครอง → ลบบัญชี | ลบ **บัญชีเข้าสู่ระบบจริง** และ Session, Push ของผู้ปกครอง, ลิงก์การเข้าดูนักเรียน | ข้อมูลตัวนักเรียนและประวัติการเรียน |

**เหตุผลที่ลบครูและข้อมูลตัวนักเรียนแบบเก็บประวัติ (soft archive):** หากลบข้อมูลการเช็กชื่อ การหนีเรียน หรือคะแนนทุกชนิดแบบถาวรจะทำลายหลักฐานการดูแลนักเรียนย้อนหลัง และอาจกระทบการตรวจสอบข้อเท็จจริง ทั้งการลบและเก็บประวัติจะบันทึก audit log พร้อมผู้ดำเนินการ

**ข้อจำกัดการเก็บประวัติ:** นักเรียนที่ถอนข้อมูลยังคงมีเรคอร์ดในตาราง `students` เพื่อรักษาความถูกต้องของ Foreign Key และอาจยังยึดเลขที่เดิมของห้องในข้อกำหนด UNIQUE เดิม หากต้องการนำเลขที่เดิมกลับมาใช้ ห้ามแก้ฐานข้อมูลตรง ๆ ให้ดำเนินการผ่านแผนย้ายห้องหรือปรับแบบข้อมูลอย่างตรวจสอบได้ก่อน

Admin **ไม่สามารถลบ** บัญชี Admin ผ่านหน้าบุคลากร และห้ามลบบัญชีตนเอง

## การเผยแพร่และทดสอบ

1. Worker ต้องรัน `worker/migrations/0022_admin_account_archive.sql` (เพิ่ม `deleted_at` ใน `users` และ `students`) ก่อนใช้เมนูลบ
2. Cloudflare Pages ต้องอัปเดต `web/portal-ui.js`, `web/portal-mobile.css`, `web/app.js`, `web/portal-admin.js` และ `web/admin-settings.js`
3. ทดสอบบนบัญชี Admin, ครู, ผู้ปกครองอย่างน้อย 1 ราย และนักเรียนที่มี/ไม่มีประวัติคะแนน
4. ทดสอบว่าลบบัญชีผู้ปกครองแล้ว เข้าระบบไม่ได้และไม่สามารถดูบุตรหลานได้อีก ขณะที่นักเรียนยังคงมีข้อมูลการเรียน
5. ทดสอบสิทธิ์ผู้ปกครองที่มีบุตรหลานหลายคน และบัญชีที่ไม่มีการเชื่อมไม่สามารถดูรายชื่อห้องหรือประวัติผู้อื่น

ชุดทดสอบ: `tests/admin-delete-guardian-history.test.mjs`, `tests/admin_identity_archive_migration_test.py` และ `tests/portal_privacy_test.py`.
