# นำเข้าทะเบียนนักเรียนแบบ Upsert + ข้ามแถวผิดพลาด

ในเมนู **จัดการนักเรียน → นำเข้าจาก Excel/CSV ทั้งโรงเรียน** ให้นำเข้าข้อมูลหลายห้องในไฟล์เดียว ระบบตรวจตาม **เลขประจำตัวนักเรียน**:

- เลขประจำตัว **ยังไม่มี**: เพิ่มนักเรียนใหม่ และสร้างบัญชีนักเรียนเมื่อมี Username/Password
- เลขประจำตัว **มีอยู่และอยู่ห้องเดียวกับในไฟล์**: อัปเดต **ชื่อและเลขที่** กับแถวการสังกัดห้องปัจจุบัน โดยคง `students.id` และบัญชีผู้ปกครอง
- บัญชีเดิม: Username ใหม่ที่ไม่ชนกับบุคคลอื่นสามารถอัปเดตได้; รหัสผ่าน **ว่าง = คงรหัสเดิม**, ใส่รหัสใหม่ = ตั้งรหัสใหม่อย่างปลอดภัย; ชื่อในบัญชีจะอัปเดตตามทะเบียน
- เลขประจำตัวเดิมที่ไฟล์ระบุ **คนละห้อง**: ข้ามและแจ้งใช้แผนย้ายห้องตามขั้นตอนทะเบียน ไม่เปลี่ยนห้องจากไฟล์ เพื่อรักษา `student_enrollments` และประวัติเช็กชื่อเดิม
- ชนเลขที่ในห้อง, ชน Username ของบุคคลอื่น, มีข้อมูลลบ/เก็บเป็นประวัติ, ข้อมูลไม่ถูกต้อง, หรือแถวซ้ำภายในไฟล์: **ข้ามเฉพาะแถว** พร้อมแสดงเหตุผล ไม่บล็อกทั้งไฟล์
- ฝั่ง Worker ตรวจซ้ำก่อน commit **ทุกแถว** โดย `D1.batch` แยกตามนักเรียน จึง rollback เฉพาะรายการที่บันทึกไม่สำเร็จ และประมวลผลรายการถัดไปได้
- หน้ารายงานสรุป **เพิ่ม / อัปเดต / ข้าม** และแสดงรายการสาเหตุรายแถว โดยไม่แสดง Password ในผล API หรือหน้าพรีวิว

เพื่อไม่ให้สับสน แบบฟอร์มนำเข้า CSV นักเรียนที่ซ้ำในเมนู **ครูและระบบ** ถูกแทนที่ด้วยทางลัดไปยังศูนย์ทะเบียนเดียวกัน ระบบนำเข้าครูที่ปรึกษายังอยู่ที่เดิม

**ข้อจำกัดที่ตั้งใจรักษา:** ไม่ย้ายห้อง ไม่เลื่อนชั้น ไม่คืนสถานะข้อมูลลบ และไม่แก้ประวัติการเช็กชื่อโดยอัตโนมัติจากไฟล์; ใช้เมนูทะเบียนสำหรับการเปลี่ยนสถานะเหล่านี้

การใช้งาน: นำเข้าไฟล์โดยเลือก preview ตรวจแต่ละแถวแล้วเลือกบันทึก; ระหว่างบันทึกข้อมูลจะส่งเป็นชุดย่อย แต่ Worker ดำเนินการแยกทีละแถวเพื่อให้ผิดแถวหนึ่งไม่กระทบอีกแถว
