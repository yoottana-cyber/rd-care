# RD CONNECT • ข้อความถึงนักเรียนรายบุคคล

## ส่งข้อความจากฝ่ายกิจการนักเรียน
1. เข้าสู่ระบบครูที่ได้รับสิทธิ์ฝ่ายกิจการนักเรียน หรือบุคลากร/ผู้ดูแลระบบ
2. เปิด **ฝ่ายกิจการนักเรียน → ✉️ ส่งข้อความนักเรียน**
3. ค้นหาด้วยเลขประจำตัวหรือชื่อ เลือกนักเรียนเพียง 1 คน
4. กรอกหัวข้อและข้อความ เช่น "เชิญมาพบฝ่ายกิจการนักเรียน" และ "กรุณามาพบฝ่ายกิจการนักเรียนในช่วงพักกลางวัน"
5. ตรวจชื่อและห้องเรียนก่อนกดส่ง — ระบบเก็บข้อความลงกล่องข้อความนักเรียนทันที

## นักเรียนอ่านข้อความ
- เปิดแอป RD CONNECT นักเรียน → **✉️ ข้อความ**
- เห็นเฉพาะข้อความที่ส่งถึงตนเอง และกด **รับทราบ / อ่านแล้ว**
- ฝ่ายกิจการคนที่ส่งดูประวัติข้อความของตนและสถานะการเปิดอ่านได้
- Push แจ้งเพียง "มีข้อความใหม่จากโรงเรียน" และเปิดแอปเข้าสู่ระบบก่อนดูรายละเอียด
- หากยังไม่เปิดรับ Push ข้อความยังอยู่ในกล่องข้อความ ไม่สูญหาย

## สิทธิ์และความเป็นส่วนตัว
- ผู้ส่ง: admin, staff หรือ teacher ที่ได้รับมอบหมาย `student_affairs` เท่านั้น
- ผู้รับ: บัญชี student ที่เปิดใช้งานเท่านั้น; ผู้ปกครองและนักเรียนคนอื่นอ่านไม่ได้
- ไม่แสดงชื่อ รายละเอียดนัดหมายหรือข้อความบนล็อกสกรีน
- ข้อความไม่ใช่การสนทนา 2 ทาง ไม่มีฟังก์ชันตอบกลับ
- จำกัด 80 ข้อความต่อผู้ส่งใน 24 ชั่วโมง และเว้น 1 นาทีระหว่างการส่งซ้ำถึงนักเรียนคนเดียวกัน
- ต้องส่งข้อความที่สุภาพ เหมาะสม และจำเป็นต่อกิจการโรงเรียน ไม่ควรใส่รายละเอียดอ่อนไหว
