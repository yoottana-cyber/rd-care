# RD CONNECT — ระบบออกแบบ UI (2026)

## แนวคิด

- อัตลักษณ์โรงเรียนรัษฎา: เขียวมรกต น้ำเงินฟ้า ใช้สีเสริมม่วง/ส้ม/ชมพูอ่อนเพื่อแยกประเภทงาน
- พื้นที่ทำงานหลักใช้พื้นขาว ตัวอักษรสีเข้ม ระยะห่างสม่ำเสมอ มุมโค้ง 12–23px และกรอบบางที่มองเห็นชัด
- มือถือเป็นเป้าหมายสำคัญ: ปุ่มสัมผัสขั้นต่ำประมาณ 43px, เมนูล่าง 5 รายการ, เปิดเมนูเพิ่มเติมแล้วแยกหมวดงาน
- ลดความสับสนด้วย breadcrumbs/ชื่อหน้าและคำอธิบายสั้นบนทุกหน้ายกเว้น Dashboard
- ใช้สีเพื่อช่วยการมองเห็นควบคู่กับข้อความ ไม่ใช้เพียงสีแสดงสถานะเช็กชื่อ

## โครงสร้างไฟล์

- `web/rd-design-system.css` — ระบบสี รูปทรง ระยะห่าง ฟอร์ม ตาราง ปุ่ม โหมดมืด การตอบสนองขนาดหน้าจอ และองค์ประกอบร่วมทั้งหมด (โหลดเป็นไฟล์สุดท้ายใน `index.html`)
- `web/navigation-ui.js` — จัดกลุ่มเมนูที่ผู้ใช้ได้รับสิทธิ์อยู่แล้ว ค้นหาเฉพาะเมนูที่มีสิทธิ์ ข้อความอธิบายหน้า
- `web/app.js` — แสดงเมนูด้านข้างที่แบ่งหมวด ช่องค้นหา และส่วนหัวตามหน้าปัจจุบัน
- `web/mobile-nav.js` — แถบนำทางล่างและรายการเมนูมือถือแยกหมวด สามารถปิดด้วย Escape และคืนโฟกัสปุ่มเปิด
- `web/portal-mobile.css` — ยังคงโครงสร้างเดิมของหน้าผู้เรียนและผู้ปกครอง; `rd-design-system.css` เพิ่มสีตาม `data-role`
- `web/sw.js` — ต้องเพิ่มเลขเวอร์ชัน cache ทุกครั้งเมื่ออัปเดต UI สำหรับเครื่องที่ติดตั้ง PWA

## การรักษาสิทธิ์และฟังก์ชัน

- `groupNavigation(navs)` รับรายการที่ API/session ตรวจสิทธิ์ไว้แล้ว **ไม่มีเมนูเพิ่มสิทธิ์** ให้ผู้ใช้ที่ไม่ได้รับอนุญาต
- เมนูบน Desktop/Mobile ใช้ `data-tab` ที่ระบบ `showTab` จัดการอยู่แล้ว
- ตัวกรองเมนูเป็น client-side navigation search เท่านั้น ไม่ค้นข้อมูลส่วนบุคคลหรือออกคำขอ API
- ไม่แก้ API, Push, VAPID, QR มาสาย, บัญชีหรือข้อมูลเช็กชื่อ
- รักษา Dark Mode และ `prefers-reduced-motion` รวมถึง `:focus-visible` สำหรับผู้ใช้คีย์บอร์ด
