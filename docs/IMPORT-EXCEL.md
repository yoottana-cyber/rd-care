# นำเข้ารายชื่อนักเรียน RD Care (ข้อมูลจำลองเท่านั้น)

## รูปแบบ

เปิดเว็บทดลอง Cloudflare Pages → **นักเรียน** → เลือกห้องเรียน → ส่วน **นำเข้ารายชื่อนักเรียน Excel / CSV**

รองรับ `.xlsx` (Sheet 1 หรือไฟล์ที่มี `xl/worksheets/sheet1.xml`) และ `.csv` แบบ UTF-8 สูงสุด 60 คนต่อครั้ง ไฟล์ `.xlsx` ไม่เกิน 3MB

| roll_no | student_no | full_name |
|---|---|---|
| 1 | DEMO9001 | นักเรียนตัวอย่าง หนึ่ง |
| 2 | DEMO9002 | นักเรียนตัวอย่าง สอง |

ชื่อคอลัมน์หากมีหัวตารางต้องเป็น `roll_no,student_no,full_name`. โปรแกรมอ่านสามคอลัมน์แรกเท่านั้น

**ข้อควรระวัง:** ตั้งประเภทคอลัมน์ `student_no` เป็น Text ใน Excel เพื่อรักษาศูนย์นำหน้า. รูปแบบเก่า `.xls` ยังไม่รองรับ. Excel สูตรที่ไม่ได้เก็บผลลัพธ์อาจได้ช่องว่าง; แนะนำใช้ค่าข้อความ/ตัวเลขจริง

## การทำงาน

1. เลือกไฟล์ Excel/CSV หรือวางข้อความ CSV แล้วกด **ตรวจสอบข้อมูลก่อนนำเข้า**
2. Browser อ่านไฟล์ Excel ภายในเครื่องด้วย `DecompressionStream('deflate-raw')` และ XML parser โดยไม่โหลดไลบรารีจาก CDN
3. หน้าเว็บส่งเฉพาะข้อมูลสามคอลัมน์สำหรับนักเรียนจำลองไปยัง API `POST /api/admin/import-students/preview`
4. API ตรวจข้อมูลไม่ครบ, เลขที่ซ้ำกันในไฟล์, รหัสนักเรียนซ้ำในไฟล์, รหัสนักเรียนที่มีอยู่แล้วใน **ทุกห้อง**, และเลขที่ซ้ำในห้องที่เลือก (รวมรายการพักข้อมูล)
5. หน้าเว็บแสดงสถานะและข้อผิดพลาดแยกแต่ละแถว; ปุ่มยืนยันปิดไว้หากมีข้อผิดพลาด
6. เมื่อยืนยัน API ตรวจซ้ำอีกครั้ง และบันทึกแบบชุดธุรกรรมที่ rollback ทั้งหมดหากแถวใดเกิด conflict
7. ดูนักเรียนใหม่ในห้องเรียน หรือแก้ไขข้อมูลโดยไม่ลบประวัติ

**ยังไม่ได้ออกแบบให้ใช้ข้อมูลนักเรียนจริง** หรือยืนยันการรองรับ Excel รูปแบบซับซ้อนทุกชนิด. โปรดทดลองกับข้อมูลสมมติและตรวจ Browser Compatibility ก่อน Pilot

## วางแผนย้ายห้อง

ในหน้าแก้ไขนักเรียน เลือกปีการศึกษา พ.ศ., ภาคเรียน และห้องปลายทาง แล้วกด **บันทึกแผนย้ายห้อง**.

ระบบบันทึกลงตาราง `student_transfer_plans` เท่านั้น **ไม่ย้ายห้องจริงและไม่เปลี่ยนประวัติการเช็กชื่อ**. การย้ายจริงจะเพิ่มในเฟสที่มีข้อมูลสังกัดห้องรายช่วงเวลาและแก้รายงานย้อนหลังให้ใช้ข้อมูลสังกัด ณ วันเกิดเหตุ

## โครงสร้าง Backend

- `worker/src/student-import.js`: กฎตรวจซ้ำและผลรายแถว
- `worker/src/worker.js`: endpoints สำหรับ Preview/Commit และ Transfer Plans (admin เท่านั้น)
- `worker/migrations/0003_student_transfer_plans.sql`: ตารางแผนย้ายห้อง
- `web/xlsx-reader.js`: ตัวอ่าน XLSX ในเบราว์เซอร์ผ่าน API มาตรฐาน ไม่มี CDN
