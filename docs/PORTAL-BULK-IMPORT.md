# RD CONNECT • นำเข้าบัญชีนักเรียนและผู้ปกครองทั้งโรงเรียน

เมนู **ผู้ดูแลระบบ → บัญชีนักเรียนและผู้ปกครอง → นำเข้าบัญชีทั้งโรงเรียน**

## รูปแบบข้อมูล

ดาวน์โหลดไฟล์ตัวอย่าง Excel หรือ CSV ได้ในหน้าเว็บ แล้วแก้ไขตารางแผ่นงานแรก:

| คอลัมน์ | คำอธิบาย |
| --- | --- |
| `student_no` | **เลขประจำตัวนักเรียนในทะเบียน RD CONNECT** ใช้ค้นหาและจับคู่บัญชีเดิม (ต้องรักษาศูนย์นำหน้า) |
| `full_name` | ชื่อนักเรียน ถ้าใส่จะอัปเดตชื่อในทะเบียนเดิม ถ้าว่างจะใช้ชื่อเดิม |
| `student_username` | Username นักเรียน; เว้นว่างใช้เลขประจำตัวเมื่อสร้างใหม่ หรือเก็บ Username บัญชีเดิม |
| `student_password` | บัญชีใหม่ต้องกรอก 4–128 ตัว (แนะนำ 8 ตัวขึ้นไป และแตกต่างกันแต่ละคน); บัญชีเดิมเว้นว่างเพื่อรักษารหัสเดิม หรือใส่รหัสใหม่เพื่ออัปเดต |
| `guardian_name` | ชื่อผู้ปกครอง |
| `guardian_username` | Username ผู้ปกครอง; อาจใช้ชื่อเดียวกันกับหลายแถวเพื่อให้ผู้ปกครองคนเดียวเข้าดูพี่น้องได้ |
| `guardian_password` | บัญชีใหม่ต้องกรอก 4–128 ตัว; บัญชีเดิมเว้นว่างเพื่อรักษารหัสเดิม หรือระบุรหัสใหม่เพื่อตั้งรหัสใหม่ |

**สำคัญ:** ต้องนำเข้าทะเบียนนักเรียนด้วยเลขประจำตัวก่อนนำเข้าบัญชี; ไฟล์นี้ไม่สร้างห้องเรียนหรือเลขที่ใหม่โดยอัตโนมัติ และทุกบัญชีนักเรียนอิง `student_no` ไม่ใช่ชื่อหรือเลขที่นั่ง

## วิธีนำเข้า

1. เข้าเว็บในสิทธิ์ **Admin** เลือกเมนู **บัญชีนักเรียนและผู้ปกครอง**
2. เลือก **ดาวน์โหลดตัวอย่าง Excel** หรือ **CSV** แล้วแก้ไขรหัสนักเรียน Username และ Password จากข้อมูลจริง
3. อัปโหลดไฟล์ที่แก้ไขแล้วบนหน้าเดียวกัน กด **อ่านและตรวจสอบไฟล์**; หน้าตัวอย่าง **ไม่แสดง Password**
4. หากมีผู้ปกครอง ให้ตรวจสอบเอกสารและความสัมพันธ์จริง แล้วทำเครื่องหมาย **ยืนยันว่าตรวจสอบตัวตนและความสัมพันธ์**
5. กด **นำเข้า/อัปเดตทั้งไฟล์** ครั้งเดียว ระบบทยอยประมวลผลอัตโนมัติเป็นชุดเล็ก (5 แถวต่อคำขอ) เพื่อไม่ให้ Worker ทำงานเกินข้อจำกัด โดยไม่มีเพดานจำนวนแถวต่อการกดนำเข้า
6. ดูความคืบหน้า หากการเชื่อมต่อขัดข้อง รายการที่บันทึกแล้วจะไม่หาย; สามารถแก้ข้อมูลแล้วนำเข้าไฟล์เดิมซ้ำได้

## ผลเมื่ออัปโหลดซ้ำ

- **บัญชีนักเรียน:** จับคู่ `student_no` กับ `students.student_no` และบัญชีที่ผูก `student_id`; มีแล้ว **อัปเดต** ไม่มีแล้ว **สร้างใหม่** ไม่สร้างบัญชีซ้ำ
- **ผู้ปกครอง:** จับคู่กับ `guardian_username`; มีแล้วอัปเดตชื่อ/รหัสผ่าน (เฉพาะเมื่อกรอก) ไม่มีแล้วสร้างใหม่
- **ความสัมพันธ์ผู้ปกครอง:** ผูกด้วยเลขประจำตัวนักเรียนเดิม; ถ้าผูกแล้วไม่เพิ่มแถวซ้ำ สามารถใช้ผู้ปกครองคนเดียวกับพี่น้องหลายคนได้
- **Password ช่องว่าง:** สำหรับบัญชีเดิมจะเก็บแฮชและรหัสเดิม; สำหรับบัญชีใหม่ต้องระบุ Password
- **Password ที่ระบุใหม่:** จะเปลี่ยนรหัสบัญชีที่ตรงกัน และยกเลิก Session เดิม เพื่อให้ใช้รหัสใหม่ในการเข้าสู่ระบบครั้งต่อไป
- **ไม่บังคับเปลี่ยนรหัสครั้งแรก:** ทั้งบัญชีนักเรียนและผู้ปกครองที่สร้างใหม่ อัปเดต หรือรีเซ็ต และบัญชีที่มี flag เดิม จะใช้ได้โดยไม่บังคับเปลี่ยนรหัสเมื่อเข้าสู่ระบบ

การนำเข้าไม่ได้ลบผู้ปกครองรายอื่นที่ได้รับการเชื่อมโยงกับนักเรียนก่อนหน้า **หากต้องเพิกถอนความสัมพันธ์เดิม** ให้ใช้ปุ่มเพิกถอนสิทธิ์ในส่วนบัญชีผู้ปกครอง (เพื่อไม่ตัดสิทธิ์ผู้ปกครองคนอื่นโดยไม่ตั้งใจ)

## ข้อควรระวัง

- ต้องมีสิทธิ์ Admin และยืนยันว่าตรวจสอบตัวตน/ความสัมพันธ์ผู้ปกครองแล้วก่อนสร้างลิงก์เข้าดูข้อมูลนักเรียน
- ห้ามใช้เลขบัตรประชาชนเป็น Password หรือส่งไฟล์ที่มี Password ไปยังกลุ่มสาธารณะ เก็บไฟล์เฉพาะในพื้นที่โรงเรียนที่ได้รับอนุญาต และลบสำเนาที่ไม่จำเป็น
- ไฟล์ .xlsx/.csv จำกัดขนาด 8 MB ต่อไฟล์เพื่อป้องกันการใช้หน่วยความจำเกินของเบราว์เซอร์ ไม่มีการจำกัดจำนวนแถวต่อการกดนำเข้า (หากใหญ่เกินไปจึงค่อยแยกไฟล์)
- Worker ใช้ 100,000 รอบ PBKDF2 ตามโค้ดปัจจุบันซึ่งระบุว่ายังต้องผ่านการทบทวนด้านความปลอดภัยก่อนใช้จริงกับข้อมูลของผู้เรียน; ควรทดสอบระบบสิทธิ์และการจัดเก็บบัญชีให้ครบก่อนนำเข้าข้อมูลจริง
- Cloudflare Pages ต้องเผยแพร่ไฟล์ UI ล่าสุด และ Dev Worker ต้องรัน migration `0021_portal_no_forced_password_rotation.sql` ก่อนเริ่มใช้
