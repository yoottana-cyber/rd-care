# RD CONNECT — ตรวจครูที่ปรึกษาครบ 48 ห้อง

ผลตรวจบนเซิร์ฟเวอร์โรงเรียนวันที่ 31 ต.ค. 2569: 46 migrations, ห้องเรียน 48,
ห้องที่มีนักเรียน 48, นักเรียน 1,751, บัญชีนักเรียน 1,751, บัญชีผู้ปกครอง 1,751,
รายการเชื่อมผู้ปกครอง 1,751, บัญชีครู/บุคลากรที่ Active 81,
**ห้องที่มีการกำหนดครูที่ปรึกษา 47 ห้อง**,
ไฟล์สำรองล่าสุดอายุ 0 ชั่วโมง

## ระบุห้องที่ยังไม่ครบโดยไม่เปิดเผยชื่อบุคคล

ติดตั้งโค้ดจาก PR #80 เวอร์ชันล่าสุดเฉพาะในไดเรกทอรีของ Node.js App:
`/home/ratsadaa/rd-connect-school-app`
**ไม่ลบหรือทับ** SQLite ส่วนตัว/โฟลเดอร์สำรอง และ **ห้ามรัน `school:install` ซ้ำ**

จาก DirectAdmin → Setup Node.js App → Run JS Script เรียกคำสั่ง

    school:test
    school:advisor-check

คำสั่ง `school:advisor-check` เปิดฐาน SQLite ในโหมด **อ่านอย่างเดียว**
ตรวจชื่อห้องและจำนวนเด็กจากทะเบียนเพื่อชี้จุดที่ยังขาด
ตรวจช่องครูที่ปรึกษาหลัก/คนที่สอง ตลอดจนบทบาทและสถานะของบัญชีครูที่ถูกผูก
(ต้อง Active, ไม่ถูกลบ, role=teacher หรือ staff)
ไม่แสดงชื่อ/Username ครูหรือข้อมูลระบุตัวนักเรียน และไม่ส่ง Push

ตัวอย่างสิ่งที่จะเห็นเมื่อยังมี 1 ห้องว่าง (เป็นตัวอย่างรูปแบบเท่านั้น ไม่ได้ระบุว่าห้อง ม.1/1 ขาดจริง):

    ROOMS WITHOUT ADVISOR: 1.
    ASSIGN ADVISOR: ม.1/1 (active enrolled students 35).
    ADVISOR COVERAGE PENDING.

`returncode 2` = พบห้องยังไม่มีครูที่ปรึกษาหรือมีสิทธิ์บัญชีไม่ถูกต้อง
`returncode 0` = ครบ 48 ห้องและช่องครูที่ปรึกษาถูกต้อง
`returncode 1` = ตรวจไม่ได้จากสภาพแวดล้อม / SQL / permission

## วิธีแก้หนึ่งห้องที่ขาด

เข้าเว็บ RD CONNECT ด้วย Admin → **ครูและระบบ** → เมนูกำหนดครูที่ปรึกษา
เลือกเฉพาะห้องที่คำสั่งรายงาน แล้วเลือกบัญชีครูที่มีอยู่แล้ว (ถ้ามี)
เพื่อไม่สร้างบัญชีซ้ำและไม่เปลี่ยนรหัสผ่าน
หากมีครูที่ปรึกษา 2 คน ให้กำหนดครูหลักก่อนครูคนที่สอง

หากยังไม่มีบัญชีครูจริง ๆ ใช้หน้า **นำเข้าครูที่ปรึกษา**
โดยดาวน์โหลดไฟล์ Excel/CSV ตัวอย่างจากหน้าเว็บและตรวจ Preview ก่อน Commit
นำเข้าเฉพาะห้องนั้น ไม่ต้องนำเข้าครูทั้ง 81 บัญชีซ้ำ

## ยืนยันหลังแก้

1. รัน `school:advisor-check` อีกครั้ง ต้องได้ 0 ห้องที่ยังไม่มีครู และ 0 ห้องที่ผูกครูผิดเงื่อนไข
2. รัน `school:pilot-check` ควรขึ้น `advisor rooms 48`
3. ทดสอบล็อกอินครูที่ปรึกษาของห้องที่แก้ และตรวจสิทธิ์ไม่ให้เห็น/เช็กชื่อห้องอื่นที่ไม่ได้รับมอบหมาย
4. รัน `school:backup` และเก็บผลว่าผ่าน
5. Cron Jobs บน DirectAdmin ยังรอผู้ให้บริการเปิด จึงต้องสำรองข้อมูลด้วยตนเองต่อไปจนกว่า Scheduler จะพร้อม

หมายเหตุ: จำนวน `81` ใน `school:pilot-check` เป็นจำนวนบัญชี Active role teacher **หรือ staff**
ไม่ใช่จำนวนห้องหรือจำนวนครูที่ปรึกษาที่ผ่านการตรวจสิทธิ์ทั้งหมด
