# RD CONNECT — นำเข้าบุคลากรแบบข้ามบัญชีเดิม หรืออัปเดตชื่อ

สำหรับโรงเรียนรัษฎา บนแอป Node.js 24 + SQLite เดิม
`https://ratsada.ac.th/web/rd-connect-fast/`

## เข้าเมนู

เข้าสู่ระบบเป็น Admin → **ครูและระบบ / ศูนย์จัดการระบบ** → **นำเข้าข้อมูล**
แล้วเปิด **นำเข้าบุคลากร (ข้ามคนเดิม / อัปเดตชื่อ)**
หรือจาก **บัญชีบุคลากร** กด **นำเข้าบุคลากร**

เมนูนี้ **แยกจากการนำเข้าครูที่ปรึกษา**: สร้างบัญชีบุคลากรหรือปรับชื่ออย่างเดียว
ไม่ตั้งค่า/ไม่ลบครูที่ปรึกษา ไม่แก้ตารางสอน ไม่แก้สิทธิ์ฝ่ายกิจการ และไม่แตะข้อมูลนักเรียน/ผู้ปกครอง 1,751 บัญชี

## ไฟล์ตัวอย่าง (.xlsx และ .csv UTF-8)

กด **ดาวน์โหลดไฟล์ตัวอย่าง Excel** หรือ **ดาวน์โหลด CSV UTF-8** บนหน้าเว็บ

| username | full_name | role | password |
|---|---|---|---|
| teacher_demo_new | ครูตัวอย่าง คนใหม่ | teacher | เปลี่ยนเป็นรหัสผ่านเฉพาะคน |
| staff_demo_new | บุคลากรตัวอย่าง คนใหม่ | staff | เปลี่ยนเป็นรหัสผ่านเฉพาะคน |
| teacher_existing | ครูตัวอย่าง ที่มีบัญชีแล้ว | teacher | เว้นว่าง |

- `username`: ภาษาอังกฤษ/ตัวเลข/`.`/`_`/`-` ยาว 3–40 ตัว **ใช้เป็นกุญแจจับคู่คนเดิม** ไม่ใช้ชื่อบุคคลในการจับคู่
- `full_name`: ชื่อ–สกุล ไม่เกิน 100 ตัว
- `role`: `teacher` (ครู) หรือ `staff` (ฝ่ายกิจการนักเรียน) **ห้าม `admin`**; role `staff` มีสิทธิ์ต่างจากครูและควรกำหนดเฉพาะผู้มีหน้าที่จริง
- `password`: **คนใหม่ต้องมีรหัสผ่าน** ตามนโยบายของบัญชีโรงเรียนปัจจุบัน: `teacher` ≥ 10 ตัว และ `staff` ≥ 12 ตัว; อย่าใช้เลขบัตรประชาชน 13 หลัก
- สำหรับ **คนเดิม** เว้นช่อง Password ว่างได้ และไม่ว่ากรอกหรือไม่ **การนำเข้าไม่เปลี่ยนรหัสผ่านเดิม**
- **ห้ามนำเข้าตัวอย่างโดยไม่แทนข้อมูลจริง** และไม่โพสต์ไฟล์รหัสผ่านลงสาธารณะ

## เลือกวิธีจัดการคนเดิม

### แบบ 1 — ข้ามบัญชีที่มีอยู่แล้ว (ค่าเริ่มต้น/แนะนำ)
- Username มีอยู่ → **ข้าม** ไม่เปลี่ยนชื่อ รหัสผ่าน สิทธิ์ บทบาท หรือสถานะ
- Username ยังไม่มี → **เพิ่มบัญชีใหม่** พร้อม Role/Password จากไฟล์
- ไฟล์เดิมนำเข้าซ้ำได้โดยไม่มีการสร้างบัญชีใหม่ซ้ำสำหรับ Username เดิม

### แบบ 2 — อัปเดตชื่อบุคลากรเดิม + เพิ่มคนใหม่
- Username มีอยู่ → **อัปเดตเฉพาะ `display_name`** จาก `full_name`
- **คง** Username, รหัสผ่าน, Role, Session, สถานะพักบัญชี, ครูที่ปรึกษา, ตารางสอน และสิทธิ์ฝ่ายกิจการนักเรียนเดิม
- หาก Role ในไฟล์ของบัญชีเดิมไม่ตรงกับ Role ในระบบ ระบบ **ปฏิเสธแถวนั้น** ให้แก้สิทธิ์ผ่านเมนูจัดการบัญชีด้วยตนเองก่อน
- Username ยังไม่มี → **เพิ่มบัญชีใหม่** ตามข้อมูลไฟล์

### การตรวจสอบก่อนบันทึก
1. สำรอง SQLite ด้วย Run JS Script → `school:backup`
2. เลือกไฟล์ `.xlsx` หรือ `.csv` และเลือกโหมด
3. กด **ตรวจสอบทั้งไฟล์ก่อนบันทึก** ระบบตรวจ CSV/Excel และตรวจ Username ที่มีอยู่ในฐานข้อมูลทีละไม่เกิน 50 รายการ
4. ดูแถวผล `เพิ่มใหม่ / อัปเดต / ข้าม / ผิดพลาด` ก่อนกดปุ่มยืนยัน
5. หากพบข้อมูลผิดพลาดแม้หนึ่งแถว ระบบ **ไม่อนุญาตให้เริ่มบันทึก** จนกว่าจะจัดการไฟล์และตรวจใหม่
6. เมื่อกดยืนยัน ระบบบันทึกเป็นธุรกรรมชุดละไม่เกิน 5 คน โดย **ไม่แสดงรหัสผ่าน** ใน Preview หรือ API response
7. หากเครือข่ายขัดข้อง บางชุดอาจบันทึกแล้ว ให้ตรวจรายชื่อในระบบแล้วตรวจ Preview ใหม่ก่อนทำซ้ำ ไม่กดบันทึกซ้ำโดยไม่มีการตรวจ
8. สำรองด้วย `school:backup` อีกครั้งหลังนำเข้าสำเร็จ

**ข้อจำกัด**: ยังไม่มีฟังก์ชันเปลี่ยน Password หรือ Role แบบกลุ่มเพื่อป้องกันการเปลี่ยนสิทธิ์โดยไม่ได้ตั้งใจ เมื่อต้องการเปลี่ยนข้อมูลดังกล่าวให้ใช้หน้าจัดการบุคลากรและกระบวนการรีเซ็ตรหัสผ่านที่ได้รับอนุญาตโดยเฉพาะ
