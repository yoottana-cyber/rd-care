# RD CONNECT — ตารางครูที่ปรึกษาและหัวหน้าระดับชั้น

ในระบบฝ่ายกิจการนักเรียน → **หัวหน้าระดับ/ที่ปรึกษา**

## จัดการครูที่ปรึกษา

- ตารางแสดงห้องเรียนทั้งหมด 48 ห้อง: ห้อง, ครูที่ปรึกษาคนที่ 1, คนที่ 2, สถานะ, ปุ่มบันทึก
- ช่องกรองด้านบน: ค้นหาหมายเลขห้อง/ชื่อครู/Username, เลือกระดับ ม.1–ม.6, เลือกห้องที่ยังไม่ได้กำหนด หรือห้องที่มีครูเพียง 1 คน
- ในช่องชื่อครู ให้พิมพ์ชื่อหรือ Username เพื่อให้ **Dropdown ค้นหา** แสดงตัวเลือก แล้วคลิกเลือกจากรายการ ชื่อซ้ำกันจะมี Username กำกับ
- กดบันทึกเฉพาะแถวที่ต้องการ ไม่เปลี่ยนอีก 47 ห้อง; กำหนดครู 1–2 คนได้ โดยคนที่ 1 และคนที่ 2 ห้ามเป็นคนเดียวกัน
- ต้องเลือกจากรายการที่มีอยู่จริง หากพิมพ์ชื่อไม่ตรงกับบัญชีที่เปิดใช้งานจะไม่ยอมบันทึก
- หากลบชื่อทั้งสอง ระบบจะถามยืนยันก่อนถอนสิทธิ์การเป็นครูที่ปรึกษาของห้องนั้น
- ตารางมือถือเลื่อนในแนวนอนได้ โดยหัวตารางอยู่ด้านบน

## หัวหน้าระดับ ม.1–ม.6

- ช่องค้นหาเลือกได้ทั้งครูผู้สอน (role=teacher) และครูที่ทำงานฝ่ายกิจการ (role=staff) ที่บัญชี active และยังไม่ถูกลบ
- ครูที่มีสิทธิ์ฝ่ายกิจการเพิ่มโดยการมอบหมายพิเศษ แต่บทบาทยังเป็น teacher ยังคงเลือกได้เหมือนเดิม
- บันทึกหัวหน้าระดับผ่าน API ที่ตรวจสิทธิ์ฝ่ายกิจการ/ผู้ดูแล; ไม่เปลี่ยน role, student_affairs grant, รหัสผ่าน หรือ Session ของครู

## ตรวจหลัง Deploy บนสำเนาทดสอบก่อน

1. รัน `school:test` กับโค้ดสาขา PR และฐานทดสอบแยก (การทดสอบสังเคราะห์)
2. ใช้บัญชีฝ่ายกิจการบนแอปทดสอบ: ตรวจครบ 48 แถว ค้นชื่อ/Username ในช่อง Dropdown และทดสอบการกรองห้อง
3. ทดสอบบันทึกครูในห้องจำลอง 1 ห้อง และเลือกครู role=staff เป็นหัวหน้าระดับ
4. ตรวจ API ว่าปฏิเสธบัญชีไม่ใช่ครู/ครูพักบัญชี และครูที่ไม่ใช่ฝ่ายกิจการไม่สามารถกำหนดหัวหน้าระดับ
5. สำรองฐานจริงด้วย `school:backup` ก่อนอัปเดตและทดสอบสิทธิ์ หลัง Deploy ห้ามรัน `school:install` ซ้ำ

ไม่แก้รายชื่อครู ห้องเรียน นักเรียน ผู้ปกครอง หรือ Push บนระบบโรงเรียนระหว่างพัฒนา PR นี้
